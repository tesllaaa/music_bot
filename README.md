# 🎉 Party Music Bot

Telegram-бот для управления музыкальной очередью на вечеринках. Гости могут добавлять треки из VK, голосовать за пропуск и получать AI-рекомендации.

## ✨ Возможности

### 🎵 Управление очередью
- **Добавление треков** — кидай ссылки VK прямо в чат
- **Автоматический парсинг** — бот сам определяет название трека
- **Просмотр очереди** — список всех добавленных треков
- **Текущий трек** — что играет прямо сейчас

### ⏭ Система голосования
- **Демократичный скип** — трек пропускается только при достаточном количестве голосов
- **Защита от накрутки** — один пользователь = один голос
- **Настраиваемый порог** — количество голосов для скипа

### 🤖 AI-рекомендации
- **Умный DJ** — опиши атмосферу, получи подборку треков
- **Интеграция с OpenRouter** — доступ к мощным LLM моделям
- **Контекстные советы** — бот понимает настроение и жанр

### 📊 Статистика
- **Топ треков** — самые популярные песни вечеринки
- **История добавлений** — кто что добавлял

### 🎨 Удобный интерфейс
- **Кнопочное меню** — не нужно запоминать команды
- **Inline-подтверждения** — защита от случайных действий
- **Эмодзи** — красивые сообщения

## 📦 Установка

### Требования
- Python 3.11+
- pip
- Telegram Bot Token
- OpenRouter API Key (для AI)

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/yourusername/party-music-bot.git
cd party-music-bot
```

### Шаг 2: Создание виртуального окружения

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/macOS
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Файл requirements.txt

```
pyTelegramBotAPI==4.14.0
python-dotenv==1.0.0
requests==2.31.0
beautifulsoup4==4.12.2
openai==1.6.0
```

## ⚙️ Настройка

### Шаг 1: Создание бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Введи имя бота (например: `Party Music Bot`)
4. Введи username (например: `party_music_dj_bot`)
5. Скопируй полученный токен

### Шаг 2: Получение OpenRouter API Key

1. Зарегистрируйся на [openrouter.ai](https://openrouter.ai)
2. Перейди в раздел API Keys
3. Создай новый ключ
4. Скопируй его

### Шаг 3: Создание файла .env

```bash
cp .env.example .env
```

Отредактируй `.env`:

```env
# Telegram Bot
TOKEN=your_telegram_bot_token_here

# OpenRouter AI
OPENROUTER_API_KEY=your_openrouter_api_key_here

# Опционально: модель AI (по умолчанию google/gemini-2.0-flash-001)
AI_MODEL=google/gemini-2.0-flash-001
```

## 📝 Команды бота

### Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота, показ меню |
| `/help` | Справка по командам |
| `/add <ссылка>` | Добавить трек в очередь |
| `/now` | Текущий трек |
| `/queue` | Показать очередь |
| `/skip` | Голосовать за пропуск |
| `/top` | Топ популярных треков |
| `/vibe` | AI-подбор музыки |
| `/clear` | Очистить очередь |
| `/hide` | Скрыть клавиатуру |

### Кнопки меню

| Кнопка | Действие |
|--------|----------|
| 🎵 Сейчас | Текущий трек |
| 📜 Очередь | Список треков |
| ⏭ Скип | Голос за пропуск |
| 🔥 Топ | Статистика |
| 🤖 AI Вайб | Рекомендации |
